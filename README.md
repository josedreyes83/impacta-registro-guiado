# IMPACTA - Registro guiado

Aplicación web estática para el registro guiado de información agregada de proyectos IMPACTA.

## Desplegar en Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fjosedreyes83%2Fimpacta-registro-guiado&project-name=impacta-registro-guiado&repository-name=impacta-registro-guiado-vercel)

## Alcance
- Captura paso a paso.
- Ayudas contextuales.
- Validaciones básicas.
- Guardado local en el navegador.
- Respaldo JSON.
- Diseño basado en el manual de marca IMPACTA.

## Privacidad
No registrar información identificable de pacientes. Esta versión es un MVP de captura agregada y no sustituye revisión metodológica, clínica ni jurídica.

## Despliegue
Compatible con Vercel como sitio estático sin proceso de build.
